# v0.5.3 实机验收

构建、主机渲染与宿主机音频校验都不替代以下实际体验。刷写是否完成及启动日志见单独的 device-installation.json；physical_acceptance 只在实际操作完成后确认。本版已刷入实机并确认能正常启动，下面每一条仍需在实机上逐项勾选。

本版只有四个页面：**首页 → 单词卡片**，以及从首页长按进去的 **设置 → 字体许可**。方案里删掉的东西（菜单页、单元分类页、句子页、生词本、`voices` 分区）不该在设备上留下任何痕迹，验收时也当反面清单用。

## 启动

- 冷启动、声卡初始化；确认版本 0.5.3。
- 启动日志出现 `Validated 60 local voice clips at 16000 Hz`，**不是** 131 段，也不该出现 `Sentence pack missing` 或任何分区缺失提示。
- 全程无 `W` / `E` 级别日志；初始化完成后堆余量正常（本机实测 `free=180304 largest=114688`）。
- **没有 `voices` 分区**：`partitions.csv` 只有 nvs / phy_init / factory / cardid 四项，分区表里找不到第二块 4 MB 以上的数据区。

## 首页

- 首页只显示项目方提供的插画底图，底部一行固定文案「单击开始 · 长按设置」——不再是「按任意键继续」，也不再有任何叠在图上的入口按钮。
- 单击右侧**三个键中任意一个**（A 上 / B 中 / C 下）都直接进入单词卡片；三个键的行为一致。
- 长按**任意一个键 1 秒**，进入设置页；按住不放不会先闪进卡片再跳到设置。
- 全流程看不到小熊：首页、单词卡片、设置、字体许可各页都没有吉祥物，也没有眨眼/跟读/庆祝动画。

## 单词卡片

- 卡片顶部一行是进度 `背单词 n / 60`；从上往下依次是 112×112 的插画、英文单词、音标、中文释义。
- 中文释义**一直显示**，不需要翻面、也没有翻面这回事。
- 音标常显在英文下方（`apple` 显示 `/ˈæpəl/`），字符无方框、无缺字。
- 底部是**三个小号横排按钮**，按钮上写的就是要按的那个键：`A 返回` `B 下一个` `C 发声`。不是三条占满整屏宽的竖排按钮，也不该有第四个按钮。A 是右侧最上面那个键，B 中间，C 最下面。
- 卡片页上**没有任何被点亮/高亮的按钮**：三个按钮都是未选中的浅色底，因为它们各自就是一个键，不需要先移动焦点。
- 进卡片默认**不发音**；按一下 C 才出声，按一下 B 直接翻到下一张，且仍是安静的。
- **图明显变大**：112×112 的方块与米色页面应当**看不出边界**（脚本已按 alpha 裁到插画、并把透明部分合成成页面色 `#F7F3E7`），重点看白色颜料块、兔子的身体、钟面和页面底色几乎同色时有没有被啃掉或留白边，以及插画边缘的柔光是不是自然淡出、没有一圈硬边。
- 按 C 读一遍这个单词；**读的时候不翻页**，读完停在原处。
- 按 B 换一张，按 A 回首页。按住任意键 1 秒在卡片上**什么都不做**（只算一次活动）。
- **随机且不重复**：换 60 张的过程中同一个词不该出现两次；走满 60 张后重新洗牌，且新一批的第一张不是刚离开的那张。连续两次从首页进入，出图的顺序应当不同——顺序不能是固定的词表顺序。

## 设置与许可

- 设置页四项：`减小音量并试听` / `增大音量并试听` / `查看字体许可` / `返回首页`，底部提示 `A / B 切换 · C 确认`；**没有**「我会了 %u / %u 个词」那行字。
- 改音量会立刻试听一段，音量数字跟着变；调到 0 和 100 到底不再越界。
- 「返回首页」回到首页；字体许可页 `上一页` / `下一页` / `返回`，底部提示 `A / B 切换 · C 确认`，返回落到设置页。
- 长按在设置页和许可页上不跳页。

## 语音

- 音量默认 80%，可调并保存；实际扬声器清楚、无明显失真、爆音或截尾；重点听 20 ms 帧的连续朗读有没有断续或爆音。
- 60 段单词朗读逐段听过一遍，没有串音、截断或空白。

## 电源与持久化

- 播放期间不熄屏；闲置 60 秒熄屏；唤醒的第一下只亮屏、不翻页也不发音。
- 音量调整后断电重启，**音量仍是调整后的值**——这一版把存档格式和 `WORD_CONTENT_VERSION`（628472539）都冻住了，所以设备上原有的存档不会被拒绝，音量不该回到 80%。若重启后音量回到 80%，说明存档被判无效，要回来查 `app_load()` 的判据。

## 稳定性

- 连续使用超过 5 分钟，无分配失败、watchdog、意外重启；观察动态最低堆和按键响应。
- 电池供电、休眠/唤醒、续航体验单独检查。

## 身份区（每次安装都要做）

- 安装**不执行全片擦除**（不跑 `erase_flash`），不写 `0x356000..0x359fff`。
- 只刷两个区域：分区表到 `0x8000`、应用到 `0x10000`。
- 刷写**前**先回读 `0x356000` 长度 `0x4000`，与 `device-backups/cardid-before.bin` 逐字节比对（SHA-256 `fae52b8fd36bf0b586a12271682f9bac77c30e14f6c816c8bd5e504ef593d1fb`，MD5 `e159680fdc0871c8f4dde33e6ecdd6ee`）。
- 刷写**后**再回读同一区域，与备份再比一次；两次都必须完全一致。
